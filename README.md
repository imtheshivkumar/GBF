# GBF Website

This repository contains the source code for the GBF (Global Business Forum) website.

## Features

- Responsive HTML/CSS design
- Information about GBF
- Simple and clean layout
- Easy to navigate sections

## How to Use

1. Download or clone the repository.
2. Open `index.html` in any browser.
3. All styles are in `style.css` and images in the `images` folder.
